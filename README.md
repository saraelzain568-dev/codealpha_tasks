# CodeAlpha Internship Tasks

This repository contains the projects and tasks completed during my **CodeAlpha Internship Program**.

## 📌 Projects

### Task 1 — AI Language Translation Tool

A Streamlit-based language translation application that allows users to translate text between different languages.

**Technologies:**

* Python
* Streamlit
* Deep Translator
* Google Translator

### Task 2 — FAQ Chatbot

An AI-powered FAQ chatbot that processes user questions and finds the most relevant answer using Natural Language Processing and similarity matching.

**Technologies:**

* Python
* Streamlit
* NLTK
* Scikit-learn
* TF-IDF
* Cosine Similarity

### Task 4 — Object Detection

An object detection and tracking project designed to identify and track objects using computer vision techniques.

**Technologies:**

* Python
* OpenCV
* Computer Vision
* Object Detection
* Object Tracking

## ⚙️ Setup

Clone the repository:

```bash
git clone https://github.com/saraelzain568-dev/codealpha_tasks.git
cd codealpha_tasks
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Running the Projects

Navigate to the required task folder and run the application.

For Streamlit projects:

```bash
python -m streamlit run app.py
```

The application will open in your browser.
