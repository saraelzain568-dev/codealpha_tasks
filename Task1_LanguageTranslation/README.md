# AI Language Translator 🌷

A simple AI-powered language translation web application built with Python and Streamlit.

## Features

- Translate text between multiple languages.
- Simple and user-friendly interface.
- Built with Streamlit.
- Uses Google Translate through the `deep-translator` library.
- Clear button to reset the input and result.

## Technologies Used

- Python
- Streamlit
- Deep Translator
- Google Translate
